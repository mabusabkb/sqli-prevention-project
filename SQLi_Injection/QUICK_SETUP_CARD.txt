┌────────────────────────────────────────────────────────────────────────────────┐
│ STEP 1: DOWNLOAD XAMPP                                                         │
└────────────────────────────────────────────────────────────────────────────────┘

  🌐 Go to: https://www.apachefriends.org/
  📥 Click: Download for Windows
  💾 Save: xampp-windows-x64-installer.exe
  ⏱️  Time: 2-5 minutes

┌────────────────────────────────────────────────────────────────────────────────┐
│ STEP 2: INSTALL XAMPP                                                          │
└────────────────────────────────────────────────────────────────────────────────┘

  1. Double-click the installer
  2. Click "Yes" if Windows asks for permission
  3. Click "Next" through all screens
  4. Install to: C:\xampp (default)
  5. Wait for installation to complete
  ⏱️  Time: 3-5 minutes

┌────────────────────────────────────────────────────────────────────────────────┐
│ STEP 3: START XAMPP                                                            │
└────────────────────────────────────────────────────────────────────────────────┘

  1. Open: XAMPP Control Panel
     (Search in Start Menu or go to C:\xampp\xampp-control.exe)
  
  2. Click "Start" next to Apache
     → Should turn GREEN and say "Running"
  
  3. Click "Start" next to MySQL
     → Should turn GREEN and say "Running"

  ✅ Both should show green "Running" status

┌────────────────────────────────────────────────────────────────────────────────┐
│ STEP 4: VERIFY IT WORKS                                                        │
└────────────────────────────────────────────────────────────────────────────────┘

  🌐 Open browser: http://localhost/
     → Should see XAMPP welcome page ✅

  🌐 Open browser: http://localhost/phpmyadmin
     → Should see phpMyAdmin interface ✅

┌────────────────────────────────────────────────────────────────────────────────┐
│ STEP 5: IMPORT DATABASE                                                        │
└────────────────────────────────────────────────────────────────────────────────┘

  In phpMyAdmin (http://localhost/phpmyadmin):
  
  1. Click "Import" tab
  2. Click "Choose File"
  3. Select: SQLi_Injection/Database/127_0_0_1.sql
  4. Click "Go"
  5. Wait for success message ✅

┌────────────────────────────────────────────────────────────────────────────────┐
│ STEP 6: COPY PROJECT                                                           │
└────────────────────────────────────────────────────────────────────────────────┘

  1. Copy entire SQLi_Injection folder
  2. Paste into: C:\xampp\htdocs\
  3. Final path: C:\xampp\htdocs\SQLi_Injection\

┌────────────────────────────────────────────────────────────────────────────────┐
│ STEP 7: RUN MIGRATION                                                          │
└────────────────────────────────────────────────────────────────────────────────┘

  Open Command Prompt:
  
  cd C:\xampp\htdocs\SQLi_Injection
  php migrate_passwords.php

  ✅ Should see: "SUCCESS: All plain text passwords migrated"

┌────────────────────────────────────────────────────────────────────────────────┐
│ STEP 8: TEST APPLICATION                                                       │
└────────────────────────────────────────────────────────────────────────────────┘

  🌐 Open: http://localhost/SQLi_Injection/index.html
  
  Login with:
    Username: admin
    Password: admin123
  
  ✅ Should redirect to admin page

╔════════════════════════════════════════════════════════════════════════════════╗
║                              TROUBLESHOOTING                                   ║
╚════════════════════════════════════════════════════════════════════════════════╝

┌────────────────────────────────────────────────────────────────────────────────┐
│ Apache won't start (Port 80 in use)                                            │
└────────────────────────────────────────────────────────────────────────────────┘

  Solution 1: Close Skype or other programs using port 80
  Solution 2: Change Apache to port 8080 in config

┌────────────────────────────────────────────────────────────────────────────────┐
│ MySQL won't start (Port 3306 in use)                                           │
└────────────────────────────────────────────────────────────────────────────────┘

  Solution: Stop other MySQL services in Windows Services

┌────────────────────────────────────────────────────────────────────────────────┐
│ Login not working                                                               │
└────────────────────────────────────────────────────────────────────────────────┘

  Solution: Run migration script again
  cd C:\xampp\htdocs\SQLi_Injection
  php migrate_passwords.php

┌────────────────────────────────────────────────────────────────────────────────┐
│ Page not found (404)                                                            │
└────────────────────────────────────────────────────────────────────────────────┘

  Check:
  1. Apache is running (green in XAMPP)
  2. Project is in C:\xampp\htdocs\SQLi_Injection\
  3. Using correct URL: http://localhost/SQLi_Injection/index.html
