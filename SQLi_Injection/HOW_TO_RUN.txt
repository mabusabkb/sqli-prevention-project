STEP 1: INSTALL XAMPP
═══════════════════════════════════════════════════════════════════════════════
□ Download XAMPP from: https://www.apachefriends.org/
□ Install to C:\xampp
□ Start Apache and MySQL from XAMPP Control Panel

STEP 2: SETUP DATABASE
═══════════════════════════════════════════════════════════════════════════════
□ Open browser: http://localhost/phpmyadmin
□ Click "Import" tab
□ Select file: Database/127_0_0_1.sql
□ Click "Go" button
□ Verify "user_db" database is created

STEP 3: COPY PROJECT TO HTDOCS
═══════════════════════════════════════════════════════════════════════════════
□ Copy entire SQLi_Injection folder to: C:\xampp\htdocs\
□ Final path should be: C:\xampp\htdocs\SQLi_Injection\

STEP 4: INSTALL COMPOSER (For Testing)
═══════════════════════════════════════════════════════════════════════════════
□ Download from: https://getcomposer.org/
□ Install Composer
□ Open Command Prompt in project folder
□ Run: composer install

STEP 5: RUN PASSWORD MIGRATION (IMPORTANT!)
═══════════════════════════════════════════════════════════════════════════════
□ Open Command Prompt in project folder
□ Run: php migrate_passwords.php
□ Wait for "SUCCESS" message
□ This converts plain text passwords to secure hashes

STEP 6: OPEN APPLICATION
═══════════════════════════════════════════════════════════════════════════════
□ Open browser
□ Go to: http://localhost/SQLi_Injection/index.html
□ Login with:
  - Username: admin
  - Password: admin123

STEP 7: TEST THE APPLICATION
═══════════════════════════════════════════════════════════════════════════════
□ Try logging in with valid credentials
□ View all users (click "View Users")

STEP 8: RUN SECURITY TESTS (Optional)

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════
Problem: "Database connection failed"
Solution: 
  - Check MySQL is running in XAMPP
  - Verify database "user_db" exists
  - Check connect.php has correct credentials

Problem: "Login not working"
Solution:
  - Run: php migrate_passwords.php
  - Clear browser cache
  - Try username: admin, password: admin123

Problem: "Page not found (404)"
Solution:
  - Verify project is in C:\xampp\htdocs\SQLi_Injection\
  - Check Apache is running
  - Use correct URL: http://localhost/SQLi_Injection/index.html

Problem: "Tests failing"
Solution:
  - Run: composer install
  - Verify database is set up
  - Run migration script
